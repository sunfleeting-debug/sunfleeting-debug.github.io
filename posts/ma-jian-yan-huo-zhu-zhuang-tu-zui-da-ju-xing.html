84. 柱状图中最大的矩形

已解答

困难

题目：给定 n 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

示例 1:

输入：heights = [2,1,5,6,2,3]

输出：10

解释：最大的矩形为图中红色区域，面积为 10

示例 2：

输入： heights = [2,4]

输出： 4

提示：

  • 1 <= heights.length <=105

  • 0 <=heights[i] <= 104

通过次数684,600/1.4M

通过率49.5%

方法一：暴力枚举所有柱子为高

思路：对每一根柱子 i，向左找到第一个比它矮的，向右找到第一个比它矮的，计算宽度求面积。

classSolution{public:int largestRectangleArea(vector<int>& heights) {int n = heights.size();int maxArea = 0;for (int i = 0; i < n; ++i) {int h = heights[i];int l = i, r = i;// 向左拓展while (l - 1 >= 0 && heights[l - 1] >= h) l--;// 向右拓展while (r + 1 < n && heights[r + 1] >= h) r++;int w = r - l + 1; maxArea = max(maxArea, h * w); }return maxArea; }};

方法二：双指针法

两个数组存比这个低的两端，再用长乘以宽，再依次遍历，选出最大的面积

classSolution {public:intlargestRectangleArea(vector<int>& heights) {intsize= heights.size(); vector<int> minleft(size); vector<int> minright(size); minleft[0] = -1;for(inti=1;i<size;i++){intt= i-1;while(t>=0&&heights[t]>=heights[i]) t = minleft[t]; minleft[i] = t; } minright[size-1] = size;for(inti= size-2;i>=0;i--){intt= i+1;while(t<size&&heights[t]>=heights[i]) t = minright[t]; minright[i] = t; }intres=0;for(inti=0;i<size;i++){intw= minright[i]-minleft[i]-1;inth= heights[i]; res = max(res,w*h); }return res; }};

方法三：标准单调栈

只开一个栈，一遍遍历同时求出左右边界，无需两个数组存边界：栈内保持下标对应高度单调递增，遇到更小高度时弹出计算矩形面积。
classSolution {public:intlargestRectangleArea(vector<int>& heights){ stack<int> st;int n = heights.size();int res = 0;// 末尾补0，强制清空栈，统一处理逻辑 heights.push_back(0);for (int i = 0; i <= n; ++i) {// 当前高度小于栈顶，说明栈顶元素找到了右边界while (!st.empty() && heights[i] < heights[st.top()]) {int curIdx = st.top(); st.pop();int h = heights[curIdx];// 左边界：栈空则-1，否则栈顶int l = st.empty() ? -1 : st.top();int w = i - l - 1; res = max(res, h * w); } st.push(i); } heights.pop_back(); // 恢复原数组return res; }};
